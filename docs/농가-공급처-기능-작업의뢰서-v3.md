## 2. 사용자 진짜 흐름 (절대 어기지 말 것)

```
[A. 시즌 발굴 — 이미 구현됨]
/research/season-pulse 에서 5점 키워드 발견 ("참외")
   ↓ 🛒 담기 클릭
   ↓ (시즌 메타 함께 저장: peak_month, seasonality_ratio, season_score)
products 테이블에 row 생성 (stage='research')

[B. 공급처 찾기 — 본 의뢰서 핵심]
상품 페이지 안 "공급처 찾기" 탭 클릭
   ↓
시스템이 자동으로 그 상품 키워드/카테고리에 맞는 농가 추천
   ↓
농가 카드: [📞 통화] [⭐ 후보 등록] [❌ 탈락]
   ↓
모바일이면 자동 발신, PC면 번호 표시
   ↓
통화 종료 → 30초 결과 기록 모달 (드롭다운 + 메모 + 다음 액션)
   ↓
가장 좋은 농가 → "이 상품 공급처로 확정" → products 표에 연결
```

**핵심 원칙:**
1. **농가 마스터 메뉴는 보조** — 진입점은 *상품 페이지 안의 "공급처 찾기" 탭*
2. **시즌 펄스 → 상품 → 공급처 찾기**가 한 흐름
3. 시즌 메타(피크월 등)는 농가 매칭/정렬에 활용

### 3.4 회사 컨텍스트 — 🚨 v1 의뢰서에서 변경

**❌ 변경 전:** "바이와이즈는 공산품이라 공급처 찾기 탭 숨김"

**✅ 변경 후:**

| `products.supply_type` | "공급처 찾기"(농가) 탭 | "도매상 찾기"(중국) 탭 |
|---|---|---|
| `domestic_vendor` | ✅ | ❌ |
| `overseas_supplier` | ❌ | ✅ |
| `both` | ✅ | ✅ |
| `null` (미정) | ✅ | ✅ |

**근거:** BUYWISE.CO는 상용화 비전 보유. 모든 가입자가 농산물+공산품 동시 운영 가능해야 함 (강의생 확장 포함). 회사 종류로 분기하면 가입자 제약 발생.

**상품 만들 때 `supply_type` 자동 추론:**
- 시즌 펄스 🛒 담기 → 키워드로 추론 ("참외" → `domestic_vendor`, "캠핑의자" → `overseas_supplier`)
- 추론 실패 시 → null (사용자가 상품 페이지에서 직접 선택)
- Claude AI haiku 한 줄 분류 호출 가능

### 3.5 농가 공유 승인 시스템 (vendor_access_grants)

**철학:** 농가 마스터는 공유 가능하되 *승인받은 사람만* 접근.

```sql
CREATE TABLE vendor_access_grants (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  grantor_company_id uuid NOT NULL REFERENCES companies(id),  -- 풀 소유자
  grantee_company_id uuid NOT NULL REFERENCES companies(id),  -- 신청자
  status text NOT NULL DEFAULT 'pending',
    -- 'pending' | 'approved' | 'rejected' | 'revoked'
  requested_at timestamptz NOT NULL DEFAULT now(),
  decided_at timestamptz,
  decided_by_user_id uuid REFERENCES users(id),
  reason text,           -- 신청 사유
  notes text,            -- 승인/거절 메모
  UNIQUE (grantor_company_id, grantee_company_id)
);
```

**RLS (vendors SELECT):**
```sql
CREATE POLICY "vendors_select_own_or_granted" ON vendors
  FOR SELECT TO authenticated
  USING (
    company_id = current_company_id()
    OR company_id IN (
      SELECT grantor_company_id FROM vendor_access_grants
      WHERE grantee_company_id = current_company_id()
        AND status = 'approved'
    )
  );
```

**`vendor_call_logs`, `product_vendor_candidates` 는 격리** (자기 회사만).

### 3.6 자동 매칭 로직 (1번 PR 범위 X — 2번 PR)

1. 상품의 `name + category + primary_keyword`에서 품목 키워드 추출
2. `vendors`의 `vendor_products`와 정규화된 키워드 매칭
3. 시즌 메타 활용: `season_peak_month` ±2개월 안이면 우선 정렬 가중치 +
4. 가공품 → 원료 환원 사전 ("딸기잼" → "딸기" 등) 적용
5. 정렬: 매칭 강도 → 시즌 적합도 → 지역 → 인증 → 최근 활성도

품목 키워드 사전: `C:\개발\크롤링\aggregate_and_classify.py`의 `PRODUCT_KEYWORDS` 활용.
