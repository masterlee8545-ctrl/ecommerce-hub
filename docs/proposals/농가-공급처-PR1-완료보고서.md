## 알아두실 점

1. **현재 데이터는 유어밸류 (주) 법인에만 들어가 있음**
   - 테스트로 그쪽에 임포트했어요
   - 다른 법인(바이와이즈, 유어옵티멀)에서 보려면 같은 CSV 를 그 법인 컨텍스트로 다시 임포트하면 됨
   - 4번 PR (공유 승인) 끝나면 한 번만 임포트해도 다른 법인이 승인받아 볼 수 있음

2. **사이소 데이터의 productKeywordsAll 컬럼은 거의 비어 있음**
   - 1,728건 중 7건만 채워져 있어요 (cyso 크롤러가 셀러 상세 페이지 안 들어가서)
   - 6번 PR 또는 별도 의뢰서에서 사이소 셀러별 상품 API 추가 호출 예정
   - 그 동안 자동 매칭은 김제몰류(256건 키워드) + 농가명/주소 매칭으로 작동

3. **사업자번호 132건 중복 → 122 row 의 also_listed_on 으로 정리**
   - 차이(132 vs 122)는 그룹 안에서도 같은 site 끼리는 중복으로 안 묶기 때문
   - 예: 영천열매마농장이 별빛촌장터와 예천장터에 각각 입점 → 1 row 에 also_listed_on=[예천장터]

4. **`주식회사 토마토마 농업회사법인` 과 `토마토마` 는 별개 row**
   - 사업자번호 비어있고 업체명이 다르기 때문에 dedup 안 됨
   - 수동 병합은 향후 운영하면서 필요하면 추가 (별도 PR)
