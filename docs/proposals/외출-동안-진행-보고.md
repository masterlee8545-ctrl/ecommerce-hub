### 작동 흐름
```
[입력] "고체 탈취제 공급처"
   ↓
1) 네이버 블로그 + 지식인 검색 (각 10건)
2) 블로그 본문에서 브랜드/업체명 키워드 추출
3) 카카오 로컬에서 각 키워드로 정확한 사업장 검색
   ↓
[결과] 9개 후보 카드 (이름 + 전화번호 + 주소 + 출처)
```
