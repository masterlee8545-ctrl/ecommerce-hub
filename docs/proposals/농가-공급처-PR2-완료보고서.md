## 알아두실 점

### 1. 사이소 농가의 키워드 매칭은 `biz_sector` 컬럼으로 작동
사이소의 `productKeywordsAll` 컬럼이 거의 비어있어서, 대신 **`biz_sector`** 텍스트 ("참외", "복숭아농사", "포도생산,가공" 같은 업종 설명) 에서 키워드 부분 일치 매칭. 6번 PR 에서 사이소 셀러별 상품 추가 크롤링하면 정확 일치(50점) 매칭으로 업그레이드됨.

### 2. 가공품 → 원료 자동 환원
"딸기잼" → "딸기" 농가, "유자청" → "감귤" 농가, "쑥떡" → "약초" 농가 식으로 약 30개 가공품 환원 사전 작동. 사전에 없는 가공품은 매칭 누락 가능 — 운영하면서 추가.

### 3. 후보 저장은 회사별 격리
형이 "이 농가 후보" 라고 표시한 건 형 회사에만 보임 (P-5). 다른 회사가 같은 농가를 후보로 만들어도 서로 안 보임.

### 4. 통화 모달은 3번 PR
지금 카드의 [📞 통화] 버튼은 `tel:` 링크만 됨 (모바일에서 자동 발신). 통화 결과 30초 기록 모달은 3번 PR.

### 5. `supply_type` 자동 추론은 5번 PR
지금은 모든 상품에 "공급처 찾기" 배너가 보입니다 (supply_type 미설정이면 노출 — ADR-012 D-2 의 "NULL → 둘 다 노출"). 5번 PR 에서 시즌 펄스 담기 시 자동으로 `supply_type='domestic_vendor'` 가 채워지면 정확하게 분기됨.
